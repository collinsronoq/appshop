# API Contract

Base path:

```text
/api/v1
```

This document defines the intended surface. OpenAPI generated by FastAPI becomes the executable contract.

## Authentication

### POST /auth/register
Create account.

### POST /auth/login
Authenticate and issue tokens.

### POST /auth/refresh
Rotate/renew access credentials.

### POST /auth/logout
Invalidate refresh session.

### GET /me
Return current user.

## Households

### POST /households
Create household.

### GET /households
List memberships/households available to current user.

### GET /households/{household_id}
Read household.

### PATCH /households/{household_id}
Rename/update household.

### GET /households/{household_id}/members
List members.

### POST /households/{household_id}/invitations
Create invitation.

### POST /invitations/{token}/accept
Accept invitation.

## Products

### GET /households/{household_id}/products
List household products.

Filters may include:

- query;
- category;
- archived.

### POST /households/{household_id}/products
Create product.

### GET /households/{household_id}/products/{product_id}
Read product.

### PATCH /households/{household_id}/products/{product_id}
Update product.

### DELETE /households/{household_id}/products/{product_id}
Archive product.

### POST /households/{household_id}/products/{product_id}/image
Upload/attach product image.

### PUT /households/{household_id}/products/{product_id}/substitutes
Replace preferred substitute configuration.

## Shopping Lists

### GET /households/{household_id}/shopping-lists
List lists.

### POST /households/{household_id}/shopping-lists
Create list.

### GET /households/{household_id}/shopping-lists/{list_id}
Read list with items.

### PATCH /households/{household_id}/shopping-lists/{list_id}
Update list.

### DELETE /households/{household_id}/shopping-lists/{list_id}
Archive list.

### POST /households/{household_id}/shopping-lists/{list_id}/items
Add item.

Supports:

- product-backed item;
- ad-hoc item.

### PATCH /households/{household_id}/shopping-lists/{list_id}/items/{item_id}
Update item.

### DELETE /households/{household_id}/shopping-lists/{list_id}/items/{item_id}
Remove item.

## Trips

### POST /households/{household_id}/shopping-lists/{list_id}/trips
Start shopping trip.

### GET /households/{household_id}/trips/{trip_id}
Read current trip.

### POST /households/{household_id}/trips/{trip_id}/items/{trip_item_id}/collect
Mark collected.

### POST /households/{household_id}/trips/{trip_id}/items/{trip_item_id}/undo
Return collected/skipped item to pending.

### POST /households/{household_id}/trips/{trip_id}/items/{trip_item_id}/skip
Skip item.

### POST /households/{household_id}/trips/{trip_id}/complete
Complete trip.

### POST /households/{household_id}/trips/{trip_id}/cancel
Cancel trip.

## Substitutions

### POST /households/{household_id}/trips/{trip_id}/items/{trip_item_id}/substitutions
Create request.

### POST /households/{household_id}/substitutions/{substitution_id}/approve
Approve.

### POST /households/{household_id}/substitutions/{substitution_id}/reject
Reject.

## Purchases

### GET /households/{household_id}/purchases
List purchase history.

Filters:

- product;
- category;
- date range;
- shopper.

### GET /households/{household_id}/products/{product_id}/purchase-history
Product-specific history.

### GET /households/{household_id}/purchase-insights/recent
Recent products.

### GET /households/{household_id}/purchase-insights/frequent
Frequently purchased products.

## Push Tokens

### POST /devices/push-token
Register/update Expo token.

### DELETE /devices/push-token/{token_id}
Revoke token.

## Error Contract

Recommended error shape:

```json
{
  "error": {
    "code": "HOUSEHOLD_ACCESS_DENIED",
    "message": "You do not have access to this household.",
    "details": {}
  }
}
```

Error codes should be stable and machine-readable.
